# 蜿蜒 · ROGUE SNAKE

一款用原生 JavaScript 写的贪吃蛇 Roguelike：吃掉食物升级、抽取遗物、堆叠标签触发协同，在不断升级的威胁和随机地形里活到最后一刻。

**无构建、无运行时依赖**——所有代码都是原生 ES6+，直接打开 `index.html` 就能玩。

---

## 快速开始

```bash
git clone <你的仓库地址>
cd <仓库目录>
```

然后任选一种方式：

- **直接双击 `index.html`**（无需构建、无需安装任何东西）
- 或起一个静态服务器（推荐，避免个别浏览器对 `file://` 的 localStorage 限制）：

```bash
python -m http.server 8000
# 打开 http://localhost:8000
```

## 操作

| 按键 | 作用 |
|---|---|
| `W A S D` / 方向键 | 移动（不能直接掉头） |
| `J` | 范围冲击，击杀敌蛇 |
| `Space` | 主动技能（冲刺 / 相位 / 诱饵 / 断尾爆发） |
| `E` | 兑换囤积者层数 |
| `Q` | 使用传承印记 |
| `X` | 主动献祭（需持有对应遗物） |
| `P` / `Esc` | 暂停 |
| `R` | 重开 |

选卡界面：`1` `2` `3` 选择，`R` / `F` 刷新，`Space` / `0` 跳过。
进化与祭坛界面：`1` `2` 选择，`Esc` 暂缓或拒绝。
结算界面：`R` 重开，`M` / `Esc` 返回菜单，`I` 选择传承。

## 玩法概览

- **一次一条命**：24 × 24 棋盘，撞墙、撞自己、撞敌人都会结束这一局。
- **吃 → 升级 → 构筑**：吃食物累积经验，升级后从 3 张遗物卡中选 1 张。稀有度参与抽取权重，并有保底机制：连续多次没见到史诗/传说后，高稀有度权重会递增。
- **遗物叠加与进化**：遗物最多 3 层，满层后可二选一进化。抽卡会轻度倾向你已有的构筑（已拥有遗物 +、能补全协同 +、会触发反协同 −），但不会替你做决定。
- **协同与反协同**：遗物带有 `经济 / 机动 / 攻击 / 生存 / 诅咒 / 召唤` 标签，特定组合触发协同，冲突组合触发反协同惩罚。协同还有强度等级（Lv1 满足标签 / Lv2 相关遗物 ≥ 3 层 / Lv3 含进化）。
- **威胁与悬赏**：威胁等级随时间提升，最高 10 级；封顶后开启终局悬赏。
- **地形与词缀**：每 5 级切换区域，随机地形（遗迹墙、冰面、沼泽、熔岩、风道、裂隙、荆棘林、反转区）与区域词缀会改变走位和风险。
- **局外成长**：结算获得基因碎片，用于解锁蛇种、遗物池、主动技能与传承。

## 项目结构

```
index.html        页面结构、菜单、玩法说明与游戏 HUD
styles.css        响应式布局、主题与弹层样式
game-data.js      静态数据表（遗物、进化、协同、地形、成就、悬赏）
game.js           游戏循环、状态机、敌人、地形、战斗、存档与输入
test.js           基于 jsdom 的逻辑回归测试
browser_checks.py 真实浏览器回归 + 桌面/移动端布局检查
regression_checks.js  由 browser_checks.py 注入的补充回归片段
```

> `game-data.js` 必须先于 `game.js` 加载：两者是普通 `<script>`，共享同一个全局词法作用域。

## 开发与测试

游戏本身零依赖；只有自动化测试需要额外装东西。

```powershell
# 语法检查
node --check game-data.js
node --check game.js
node --check test.js

# 逻辑回归（需要 jsdom，仅测试用途）
npm install jsdom --no-save
node test.js

# 真实浏览器回归 + 桌面 / 390px 布局检查（需要 Chrome + websocket-client）
python browser_checks.py
```

`browser_checks.py` 支持用 `CHROME_PATH` 环境变量指定 Chrome 路径，会使用随机调试端口与临时 profile，并在失败时打印 Chrome stderr。

## 存档

- 存档键：`rogue_snake_save_v1`（浏览器 `localStorage`）
- 存档带版本号与 `migrateSave()`，旧存档会自动补齐新增字段
- 设置界面可清空传承或重置全部进度

## 技术说明

- 纯原生 ES6+，无框架、无打包器、无运行时依赖
- 渲染使用单个 `<canvas>`，UI 与弹层用 DOM
- 游戏逻辑由 `dt` 驱动，不依赖固定帧率
- 数据与逻辑分离（`game-data.js` / `game.js`）
- 关键状态修改走统一接口：`addScore()`、`removeSnakeSegments()`、`grantShield()`、`recordEvent()`；敌人伤害与死亡统一经过 `damageEnemy()` / `killEnemy()`
